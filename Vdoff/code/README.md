# Dynamic Ron Prediction Framework

This repository provides the core training framework for the physics-guided neural network used for dynamic Ron prediction in GaN power devices.

The model combines a physics-based prediction module with a neural network that learns the residual correction, enabling improved prediction accuracy while preserving physical consistency.

The public release includes:

* Data preprocessing 
* Physics-guided neural network architecture 
* Hybrid loss function for physics regularization 
* Training pipeline 
* Prediction scripts
